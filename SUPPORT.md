# Support

Use GitHub Issues for bugs, feature requests, and design discussions.

## Before opening an issue

1. Search existing issues.
2. Run the current checks:

   ```bash
   python -m pytest
   python -m ruff check .
   authorstyle --help
   ```

3. Include your operating system, Python version, command, and error output.

## Where to ask

- Use bug reports for crashes or incorrect behavior.
- Use feature requests for new loaders, metrics, encoders, or CLI commands.
- Use discussions or issues for questions about methodology or architecture.

Do not share private writing corpora in public issues.
